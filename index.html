Project showcase

Effective configuration, made observable.

A compact FastAPI service that resolves configuration from defaults, environment-specific YAML, dotenv values, operating-system variables, and repeated CLI query overrides.

Layered precedence

Defaults → YAML → .env → APP_* environment variables → set=key=value overrides.

Safe output

Typed values are returned consistently, while the API key is always masked as ****.

Deployable API

FastAPI with permissive CORS and a public deployment workflow suitable for browser-based graders and demos.
